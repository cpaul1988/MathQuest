# 1.4.0 — learning and feedback

Includes the pending 1.3.1 tutorial. PIN remains temporarily disabled for owner testing.

## Starting check
Home → Find my starting level offers 12 untimed typed questions, three per operation. Skip/Not sure is available. No gameplay statistics or rewards are changed. Results suggest Gentle/Growing/Challenge levels based on 0–1/2/3 correct per operation. The user explicitly applies them; parents can override levels in Learning settings. This brief placement aid is not a standardized assessment. Future adaptive practice can change the levels.

## Spaced review
Misses retain the existing weak-fact behavior and also schedule a next-day review. Successful due reviews on later days advance to 3, 7, 14 and 30 days. Same-day repeats do not advance the retention stage. Review mode includes scheduled facts even when their immediate weak counter has cleared. Later mistakes restart scheduling. Dates use the device's local calendar. A correct answer is never described as permanent mastery.

## Understanding and parent summary
Optional word-problem presentation uses the current question's numbers and operation. Hints add ten frames for small sums, multiplication arrays up to 12×12, and number-bond/related-fact explanations. Settings affect future questions, preserving the current one.

Parent summaries report active days and question counts in the last seven calendar days, due review facts and missed examples. Per-operation improvement compares the last six recorded answers against the previous six, only after twelve answers exist in the new bounded history (maximum 120 total). Practice this next routes to a weak/due fact's operation or the existing recommended operation. It reports practice days, not invented session counts.

## Feedback
Profile & settings → Report a problem or suggest an idea captures up to 2,000 typed characters. An optional native diagnostic preview includes app version, Android API and up to 30 allow-listed error codes, never names/emails/account tokens or progress. Editing report fields invalidates its preview. Save report opens Android's document picker; the user chooses whether and where to share it. Nothing is submitted automatically. User-entered descriptions may contain sensitive information, so the form asks users to omit personal details.

## Chosen reward
When a selected reward becomes affordable, a one-time-per-item message celebrates it. Home exposes Request reward when funds suffice. Requests use existing reserve/refund accounting; celebration gives no extra currency. Permanent stars remain separate.

## Validation
Regression coverage includes assessment nonmutation/application, visual counts, word problems, review scheduling and same-day protection, due-fact selection, parent summary, report preview invalidation/diagnostic opt-out, and one-time reward celebration. Existing gameplay/cloud/rewards/tutorial suites pass. Signed builds/lint apply to both distributions. Physical-device visuals, keyboard, document picker and Google account flows remain pending.
